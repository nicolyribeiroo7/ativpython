# 📱 Projetos em Python com Flet

## 📌 Sobre o projeto

Este repositório reúne uma coleção de pequenos projetos desenvolvidos em **Python utilizando a biblioteca Flet**. Os exercícios têm como objetivo praticar a criação de interfaces gráficas, componentes, eventos, funções e interação com o usuário.

Entre os projetos estão exemplos simples como "Olá Mundo", cartão de apresentação, formulário, contador e uma lista de mercado.

## 🛠️ Tecnologias utilizadas

* 🐍 Python
* 🎨 Flet
* 💻 Visual Studio Code ou outro editor de código
* 🌐 Execução em navegador através do Flet

## 📂 Estrutura do projeto

| Arquivo       | Descrição                                                                 |
| ------------- | ------------------------------------------------------------------------- |
| `olamundo.py` | Primeiro exemplo utilizando Flet, exibindo uma mensagem na tela.          |
| `inicio.py`   | Estrutura inicial de um aplicativo Flet.                                  |
| `main.py`     | Aplicativo com contador, permitindo aumentar e diminuir um número.        |
| `cartao.py`   | Cartão de apresentação com nome e profissão.                              |
| `perfil.py`   | Perfil com nome, profissão, e-mail e telefone.                            |
| `form.py`     | Formulário com campo para nome, aceite dos termos e mensagem de saudação. |
| `mercado.py`  | Lista de mercado com adição, remoção e alteração da quantidade dos itens. |

## ✨ Funcionalidades

### 👋 Olá Mundo

Exibe uma mensagem simples na interface utilizando `ft.Text`.

### 👤 Cartão de apresentação

Apresenta nome e profissão em uma interface personalizada, com fundo e alinhamento definidos.

### 📋 Formulário

Permite que o usuário informe seu nome e aceite os termos de uso. Ao clicar em **Enviar**, o sistema apresenta uma saudação ou solicita que os termos sejam aceitos.

### 🔢 Contador

Possui botões para diminuir e aumentar um valor apresentado em um campo de texto.

### 🛒 Lista de mercado

Permite adicionar produtos, alterar suas quantidades e excluir itens da lista.

## 🚀 Como executar

### 1. Instale o Python

Certifique-se de que o Python esteja instalado no computador.

### 2. Instale o Flet

No terminal, execute:

```bash
pip install flet
```

### 3. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 4. Entre na pasta

```bash
cd nome-do-projeto
```

### 5. Execute um dos arquivos

Por exemplo:

```bash
python olamundo.py
```

Ou:

```bash
python mercado.py
```

Alguns dos projetos estão configurados para abrir no navegador utilizando `ft.AppView.WEB_BROWSER`.
